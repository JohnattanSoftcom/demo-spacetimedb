Centre d'exploitation temps réel — démo SpacetimeDB

Un réseau de bus fictif sur la géographie réelle de Fribourg : le poste de commande centralisé (PCC), l'application chauffeur et les bornes d'arrêt partagent la même base de données. Toute la logique métier — simulation des bus, incidents, escalades, autorisations, audit — tourne dans SpacetimeDB, sans serveur d'application ni API intermédiaire.

Scénario de démonstration

  1. Ouvrez la supervision et connectez-vous avec le code {{ supervisorCode }}.
  2. Ouvrez deux onglets chauffeur, prenez chacun un bus — essayez de prendre le même : un seul gagne.
  3. Ouvrez la borne « Fribourg, Gare » : les départs se mettent à jour à chaque seconde.
  4. Le chauffeur signale une panne : l'alerte apparaît partout, la borne affiche une perturbation.
  5. Ne prenez pas l'incident en charge pendant 30 s : il est escaladé automatiquement.
  6. Envoyez un message au chauffeur : lui seul le reçoit ; l'accusé de lecture remonte au PCC.
