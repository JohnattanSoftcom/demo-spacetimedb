Trois piliers fondamentaux

Tables

Stockage transactionnel

Le schéma, déclaré dans le code comme avec un ORM. Relationnel, en mémoire, avec journal persistant.

Reducers

Calcul côté serveur

Des fonctions transactionnelles : validation, droits, règles métier. Tout réussit, ou rien n’est écrit.

Abonnements

Réseau temps réel

Du SQL côté client. Le résultat arrive, puis chaque changement est poussé en continu.

Tout Spacetime repose sur trois piliers. Les tables : le schéma déclaré dans le code, relationnel, en mémoire avec un journal persistant. Les reducers : des fonctions transactionnelles côté serveur, où tout réussit ou rien n'est écrit. Les abonnements : le client écrit du SQL, reçoit le résultat, puis chaque changement lui est poussé en continu.
